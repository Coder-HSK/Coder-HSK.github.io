I used strings, lists, and sets to track letters, guesses, and the hidden word all at once. I learned how to manipulate text in Python, why sets are perfect for storing unique values, and how to display game state in a way that's actually readable to a human. The hardest part of this game was the design. It took me hours just deciding how to portray a hangman, and when I finally taught i can paste this design with some changes to the Python code. JS had to be more complicated. And finally got to build my first multi-stage game; one where the visuals change, the stakes grow, and every wrong guess actually means something.
